# Lore Spoilers · 作者防剧透发布器 v2.0.4

原版灵感来自 [cha1latte/lore-spoilers](https://github.com/cha1latte/lore-spoilers)（MIT）。这是仅作者需要安装的「逐条标记 + 导出防剧透角色卡」插件。

## 故障修复 (v2.0.2)
- 修复 v2.0.0 PNG 数据解析函数的括号错误（Unexpected token ';'. Expected ')'），该错误会导致整个扩展无法加载。
- 若扩展显示为灰色且无法勾选，请在 SillyTavern 的「扩展 → 管理扩展」执行「更新全部」，刷新浏览器后重新查看；仍有报错则复制 v2.0.1+ 启动诊断信息。
- 此次修复不更改原版世界书或已发布的角色卡数据。

## 安装
打开 SillyTavern → 扩展 → 安装扩展，填入：

`https://github.com/riserein/spoilers-is-unavailable`

若曾安装 v1.1，请执行「更新扩展」并刷新浏览器（必要时重启酒馆）。

## 作者端使用步骤
1. 在扩展设置中勾选「启用逐条权限管理」和「作者编辑模式」。
2. 打开要发布的角色，**绑定主世界书**并保存角色。
3. 在世界书编辑器中选择同一本主世界书。
4. 逐条标记「🌐 公开」或「🔒 隐藏 · AI可读」，可搜索或批量标记。
5. 点击「📦 发布防剧透 PNG」或「📄 发布防剧透 JSON」。
6. **只分发生成的 `-防剧透版` 文件**；酒馆原生导出仍可能包含原文！

## 玩家端效果
- 玩家不需要安装本作者插件。
- 世界书中公开条目照常显示；隐藏条目的正文变为 `LSPHIDDEN_...` 占位符，标题也换为非剧透名称。
- 卡内附有角色专属正则规则（WORLD_INFO，promptOnly=true），在生成提示词时还原秘密正文给 AI。
- **必要条件**：玩家需启用 SillyTavern 自带 Regex 扩展，并授权角色的正则脚本。若拒绝授权或用不兼容客户端，AI 只能看到占位符，不会收到原文。

## 边界和注意
- **不是加密**：虽然普通玩家翻世界书看不到秘密正文，原始正文仍存放在角色卡的 `data.extensions.regex_scripts[].replaceString` 中，可被提取。
- 保留世界书的关键词、触发、深度、常驻与顺序；触发关键词本身仍可能透露剧情。
- 为避免正文被正则替换误解析，隐藏内容包含 `$1` 或 `$<name>` 时会阻止发布。正文中的 `{{...}}` 宏仍可能提前展开。
- 当前仅处理**角色绑定的主世界书**，不处理全局 / 附加世界书。
- 导出不修改作者原世界书，也不会自动发布到网络。
- 已完成 JavaScript 静态检查和模拟角色卡、PNG 元数据、正则生成的单元测试。**尚未在用户的实际酒馆上进行端到端测试**。请先拿测试卡验证。
