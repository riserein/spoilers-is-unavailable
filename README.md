# Lore Spoilers · 作者防剧透发布器 v2.1.0

原版灵感来自 [cha1latte/lore-spoilers](https://github.com/cha1latte/lore-spoilers)（MIT）。这是仅作者需要安装的「逐条标记 + 导出防剧透角色卡」插件。

## 故障修复 (v2.0.2)
- 修复 v2.0.0 PNG 数据解析函数的括号错误（Unexpected token ';'. Expected ')'），该错误会导致整个扩展无法加载。
- 若扩展显示为灰色且无法勾选，请在 SillyTavern 的「扩展 → 管理扩展」执行「更新全部」，刷新浏览器后重新查看；仍有报错则复制 v2.0.1+ 启动诊断信息。
- 此次修复不更改原版世界书或已发布的角色卡数据。

## 安装
打开 SillyTavern → 扩展 → 安装扩展，填入：

`https://github.com/riserein/spoilers-is-unavailable`

若曾安装 v1.1，请执行「更新扩展」并刷新浏览器（必要时重启酒馆）。

## 作者端使用步骤
1. 在扩展设置中勾选「启用逐条权限管理」和「作者编辑模式」。
2. 打开要发布的角色，**绑定主世界书**并保存角色。
3. 在世界书编辑器中选择同一本主世界书。
4. 逐条标记「🌐 公开」或「🔒 隐藏 · AI可读」，可搜索或批量标记。
5. 点击「📦 发布防剧透 PNG」或「📄 发布防剧透 JSON」。
6. **只分发生成的 `-防剧透版` 文件**；酒馆原生导出仍可能包含原文！

## 玩家端效果
- 玩家不需要安装本作者插件。
- 世界书中公开条目照常显示；隐藏条目的正文变为 `LSPHIDDEN_...` 占位符，标题也换为非剧透名称。
- 卡内附有角色专属正则规则（WORLD_INFO，promptOnly=true），在生成提示词时还原秘密正文给 AI。
- **必要条件**：玩家需启用 SillyTavern 自带 Regex 扩展，并授权角色的正则脚本。若拒绝授权或用不兼容客户端，AI 只能看到占位符，不会收到原文。

## 边界和注意
- **不是加密**：虽然普通玩家翻世界书看不到秘密正文，原始正文仍存放在角色卡的 `data.extensions.regex_scripts[].replaceString` 中，可被提取。
- 保留世界书的关键词、触发、深度、常驻与顺序；触发关键词本身仍可能透露剧情。
- 为避免正文被正则替换误解析，隐藏内容包含 `$1` 或 `$<name>` 时会阻止发布。正文中的 `{{...}}` 宏仍可能提前展开。
- 当前仅处理**角色绑定的主世界书**，不处理全局 / 附加世界书。
- 导出不修改作者原世界书，也不会自动发布到网络。
- 已完成 JavaScript 静态检查和模拟角色卡、PNG 元数据、正则生成的单元测试。**尚未在用户的实际酒馆上进行端到端测试**。请先拿测试卡验证。

## 修复日志
- **v2.0.3：** 修复大型角色卡 PNG 元数据解码时的 `Maximum call stack size exceeded`；改为 16 KiB 分块读取，输出元数据改为循环编码以避免大量中间数组；补充大世界书的回归测试。

- **v2.0.4：** 彻底移除 PNG 字节转换中的数组展开调用、用 TypedArray 编码 Base64；新增导出失败阶段/调用堆栈可复制面板，并强制缓存失效。若仍报错，将错误报告发给维护者定位；更新后务必确认扩展列表显示 2.0.4。

- **v2.0.5：** 纠正错误报告会被工具栏刷新删除的问题。错误报告改为固定浮窗，覆盖单条标记、批量标记、初始化、UI 同步和角色卡导出；缩小世界书监听范围以防扩展自身触发反复重绘；界面标题显示当前实际运行的 v2.0.5。若更新后标题不是 v2.0.5，说明仍在使用旧脚本。

- **v2.0.6：** 发布流程先使用酒馆原生角色卡 JSON 导出。发布 JSON 不再读取 PNG；发布 PNG 只把它作为图片载体，旧 PNG 内嵌的世界书元数据不再被完整解析。保留 v2.0.5 的独立诊断浮窗和精确失败步骤。

## 为 10 MB 以上的复杂角色卡准备的独立发布器
如果 SillyTavern 扩展管理反复报错，可以下载本仓库的 `standalone-publisher.html` 并在电脑浏览器本地打开：
1. 在 SillyTavern 里用**原生导出**得到完整的原始 PNG（包含你的前端、MVU、世界书和全部交互）。
2. 把原始 PNG 拖进/选择导入到 `standalone-publisher.html`，不需要安装/启用 Lore Spoilers 插件。
3. 在本地网页里逐条设置世界书公开或隐藏，再下载新的防剧透 PNG。
4. 原始 PNG 不会被覆盖。此方案仍需要玩家在 SillyTavern 授权角色专属正则，且不属于真正加密。
5. **请勿用已经生成的防剧透版再加工**，必须使用作者原卡。

## 重复安装检查 (v2.1.0)
最早手动 ZIP 安装的文件夹可能是 `lore-spoilers-selective`，而 GitHub 安装的文件夹名是 `spoilers-is-unavailable`。
如果两者同时存在，它们会分别绑定世界书 UI 的事件，而且使用旧版代码时不会显示新版诊断。
v2.1.0 检查这两份安装，并提示先在扩展管理删除旧 ZIP 版。独立发布器不受此影响。

## 大卡片性能调整 (v2.1.0)
- 发布时只复制被修改的世界书条目、扩展容器，避免额外深度序列化整份 10 MB+ 卡片。
- 不修改 MVU、HTML 前端、动态脚本或玩家原有角色正则。
- 提供独立 HTML 发布器，绕开酒馆扩展脚本加载过程。
